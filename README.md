# kr3-responsive-shop
# Moth pupa | Адаптивная версия (КР №3) 📱

Адаптивная версия интернет-магазина одежды, разработанная в рамках контрольной работы №3 по дисциплине "HTML и CSS".

## 🔗 Ссылка на живой сайт
[Открыть адаптивный сайт Moth pupa](https://7hkmqq.github.io/kr3-responsive-shop/)

## 📌 О проекте
Проект создан на основе сайта из КР №1. Основная задача — адаптировать существующий многостраничный сайт под различные размеры экранов (мобильные телефоны, планшеты, десктопы) без использования CSS-фреймворков (Bootstrap).

## 🛠 Реализованные требования (Чек-лист КР №3)
- [x] Создан отдельный репозиторий для адаптивной версии.
- [x] Подключен отдельный файл `responsive.css`.
- [x] Наличие метатега `viewport` на всех страницах.
- [x] **Медиазапросы**: реализованы брейкпоинты на 992px, 768px и 480px.
- [x] **Адаптация навигации**: шапка перестраивается в колонку на мобильных устройствах.
- [x] **Адаптация карточек товаров**: карточки перестраиваются в одну колонку и занимают всю ширину.
- [x] **Адаптация таблицы**: таблица размеров сжимается (уменьшены отступы и шрифт) для мобильных экранов.
- [x] **Адаптация форм**: уменьшены отступы у формы обратной связи на маленьких экранах.
- [x] **Доступность**: проверен порядок заголовков (`h1` -> `h2` -> `h3`), у всех изображений есть атрибут `alt`.
- [x] Публикация проекта на GitHub Pages.

## 📁 Структура проекта
* `index.html` — Главная страница
* `catalog.html` — Каталог товаров
* `about.html` — О нас
* `contacts.html` — Контакты
* `style.css` — Основные стили
* `responsive.css` — Файл с медиазапросами для адаптивности
* `*.jpg` — Изображения товаров
